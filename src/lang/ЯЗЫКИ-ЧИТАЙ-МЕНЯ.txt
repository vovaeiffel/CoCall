КАК ДОБАВИТЬ НОВЫЙ ЯЗЫК В COCALL
================================

Как это устроено: все тексты в программе написаны по-русски. Для каждого
языка есть файл со списком переводов вида
    "Русская фраза": "Перевод",
Если фразы в списке нет, показывается русский текст (поэтому ничего не ломается).

ШАГ 1. Скопируйте файл  src/lang/en.ts  под новым именем, например  de.ts  (немецкий).

ШАГ 2. Откройте de.ts и поменяйте в начале:
    export const en  ->  export const de
    code: 'en'       ->  code: 'de'          (короткий код, он покажется на кнопке: DE)
    name: 'English'  ->  name: 'Deutsch'      (название языка на нём самом)
    locale: 'en-US'  ->  locale: 'de-DE'      (для времени в чате)
ШАГ 3. Переведите всё, что стоит ПОСЛЕ двоеточия (справа). Левую часть (русскую
        фразу) менять нельзя. Куски вроде {name}, {count}, {size} оставляйте как
        есть, они заменяются на имена и числа. Можно менять их порядок в предложении.

ШАГ 4. Откройте src/lang/index.ts и добавьте две строки:
    import { de } from './de';
    export const LANGUAGES: Language[] = [ru, en, de];

Готово. Язык сам появится в меню на кнопке в правом верхнем углу главного экрана,
а меню в трее тоже подхватит его. Больше ничего менять не нужно.

КАК НАЙТИ НЕПЕРЕВЕДЁННЫЕ ФРАЗЫ
Запустите программу через npm start на новом языке, походите по экранам и в
консоли разработчика (она открыта в окне VS Code-версии) выполните:
    __i18nMissing
Покажется список русских фраз, для которых ещё нет перевода. Добавьте их в файл языка.

ЕСЛИ ВЫ ДОБАВИЛИ В ПРОГРАММУ НОВЫЙ ТЕКСТ
Пишите его по-русски и оборачивайте в t('...'), а перевод добавляйте в файлы языков.
