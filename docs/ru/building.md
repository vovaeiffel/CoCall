# Сборка и разработка

[← К оглавлению](../../README.md)

Нужны [Node.js](https://nodejs.org/) (LTS) и Git или просто скачанные исходники. Все команды выполняются в папке проекта.

## Запуск для разработки

```
npm install
npm start
```

`npm start` собирает программу и открывает её. При таком запуске:

- программа открывает консоль разработчика;
- у неё отдельные настройки (папка данных `CoCall-dev`), поэтому её можно запускать рядом с установленной копией;
- крестик закрывает окно, а не сворачивает в трей;
- на одном компьютере комнату может создать только одна копия (порт 8080 один). Для проверки: одна копия создаёт комнату, другая подключается к `127.0.0.1:8080`.

## Структура проекта

| Путь | Что там |
| --- | --- |
| `src/main.ts` | главный процесс: окно, трей, обновления, автопоиск, горячая клавиша |
| `src/preload.ts`, `src/global.d.ts` | мост между окном и главным процессом |
| `src/renderer.ts`, `src/ui.ts` | окно программы: логика и интерфейс |
| `src/signaling.ts`, `src/protocol.ts` | сервер комнаты (на компьютере хоста) и сообщения |
| `src/webrtc.ts` | соединения между участниками |
| `src/audio.ts`, `src/rnnoise.ts` | звук, шумоподавление |
| `src/discovery.ts`, `src/lobby.ts` | автопоиск комнат и чат сети |
| `src/theme.ts` | цветовые схемы |
| `src/lang/` | переводы |
| `index.html` | страница и стили |
| `sounds/` | встроенные звуковые наборы |

## Собрать установщик

```
npm run dist
```

В папке `release` появятся три файла: `CoCall-Setup-x.y.z.exe`, `CoCall-Setup-x.y.z.exe.blockmap` и `latest.yml`. Первая сборка занимает 5–10 минут. Если в конце ошибка про «symbolic link», включите в Windows «Режим разработчика» (Параметры → Для разработчиков) или запустите терминал от имени администратора.

## Выпустить релиз

1. В `package.json` увеличьте `"version"` (например, с `1.0.5` на `1.0.6`).
2. `npm run dist`.
3. На GitHub: Releases → Draft a new release. Тег `v1.0.6` (то же число, что в `package.json`), название и описание.
4. Приложите **все три файла** из `release`. Без `latest.yml` автообновление не заработает.
5. «Publish release» (не черновик).

Установленные программы с версией 1.0.5 или новее предложат обновиться сами. Номер каждого следующего релиза должен быть больше предыдущего.

## Добавить язык

1. Скопируйте `src/lang/en.ts` в новый файл, например `src/lang/de.ts`.
2. В начале файла поменяйте `export const en` на `export const de`, а также `code` (короткий код для кнопки, `de`), `name` (название языка на нём самом) и `locale` (`de-DE`, нужна для времени в чате).
3. Переведите всё, что стоит справа от двоеточия. Левую часть (русскую фразу) менять нельзя. Части вроде `{name}`, `{count}`, `{size}` оставляйте, они заменяются на имена и числа.
4. В `src/lang/index.ts` добавьте `import { de } from './de';` и впишите `de` в список `LANGUAGES`.
5. Запустите `npm start`: язык появится в меню с глобусом, меню в трее тоже его подхватит.

Фразы без перевода показываются по-русски, поэтому ничего не ломается. Чтобы найти непереведённые, запустите `npm start`, походите по экранам и выполните в консоли разработчика `__i18nMissing`. Новые тексты в коде пишутся по-русски и оборачиваются в `t('…')`. Подробнее: `src/lang/ЯЗЫКИ-ЧИТАЙ-МЕНЯ.txt`.

## Свои звуки

- **Стандартный набор**: файлы `join`, `leave`, `message`, `stream-start`, `stream-stop`, `mic-on`, `mic-off` (mp3, wav или ogg) прямо в папке `sounds`.
- **Свой набор**: отдельная папка внутри `sounds` с файлами тех же имён. Не обязательно класть все: чего нет, играет из стандартных. Красивое название набора: файл `pack.txt` в папке набора, название в первой строке. Наборы из `sounds` попадают в программу при сборке.
- **Набор пользователя без пересборки**: Настройки → «Звуки» → «Открыть папку с наборами», положить туда такую же папку и нажать «Обновить список».
- **Звук для одного события**: Настройки → «Звуки» → «Свой звук…» у нужного события (до 3 МБ).

Подробнее: `sounds/ЧИТАЙ-МЕНЯ.txt`.

## Файл `src/config.ts`

В нём название программы и адрес репозитория для проверки обновлений (`GITHUB_REPO`). Если вы делаете свою копию проекта, поменяйте адрес на свой.
