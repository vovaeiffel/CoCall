# Виртуальные сети и адреса

[← К оглавлению](../../README.md)

CoCall не использует центральный сервер: участники соединяются друг с другом напрямую. Для этого им нужно «видеть» друг друга по сети. Проще всего это сделать с помощью **виртуальной локальной сети**: специальная программа создаёт общую «комнату-сеть», где у каждого свой адрес, будто вы сидите в одном Wi-Fi.

## Что подойдёт

| Вариант | Комнаты по адресу | Автопоиск комнат и чат сети | Замечание |
| --- | --- | --- | --- |
| [Radmin VPN](https://www.radmin-vpn.com/) | да | да | основной вариант, на нём всё проверялось |
| Hamachi, ZeroTier | да | должно работать | похожи на Radmin, подробно не проверялись |
| Домашняя сеть (Wi-Fi / кабель) | да | да | если все дома в одной сети |
| Tailscale | да (по адресу) | нет | рассылка по сети там не проходит |
| Интернет напрямую | да, если хост открыл порт | нет | нужно пробросить порт на роутере, не всегда получается |

«Автопоиск комнат» и «Чат сети» работают на сетевой рассылке (UDP, порт 47831), которая доходит только внутри одной сети.

## Radmin VPN: пошагово

1. Все участники скачивают и ставят Radmin VPN.
2. Один человек в Radmin VPN выбирает «Создать сеть», придумывает название и пароль и сообщает их друзьям.
3. Остальные выбирают «Присоединиться к сети» и вводят то же название и пароль.
4. В окне Radmin у каждого появится адрес вида `26.x.x.x`.
5. Дальше всё в CoCall: хост создаёт комнату, остальные заходят из списка или по адресу.

CoCall сам находит адрес Radmin и показывает его в блоке «Адрес в сети Radmin VPN», копировать ничего вручную не нужно.

## Порты и брандмауэр

- Комната слушает порт **8080** на компьютере хоста (TCP).
- Автопоиск комнат и чат сети используют порт **47831** (UDP).
- Голос, камера и экран идут напрямую между участниками. Для них порты открывать не нужно, но между участниками не должно быть блокировки.

При первом создании комнаты Windows может спросить, разрешить ли программе доступ к сети. Нажмите «Разрешить». Если друзья не могут подключиться к вам, а Radmin работает, проверьте, что брандмауэр Windows не блокирует CoCall (Параметры Windows → Брандмауэр → «Разрешить работу с приложением»). Windows может считать виртуальную сеть «общедоступной», а там доступ закрыт строже: если так, разрешите программе доступ и для общедоступных сетей.

Проверить связь можно кнопкой **«Диагностика»** на главном экране: в ней есть проверка адреса хоста без захода в комнату.

## Подключение через интернет напрямую

Это запасной вариант. Хосту нужно:

1. Узнать внешний адрес: он показан в блоке «Через интернет» (если не определился, значит, нет доступа к интернету или сервис определения адреса недоступен).
2. Открыть на роутере порт 8080 (TCP) на компьютер хоста.
3. Быть уверенным, что у провайдера «белый» (не общий) адрес.

Если что-то из этого не получается, используйте виртуальную сеть. Для большинства домашних подключений она проще и надёжнее.

Для соединения голоса напрямую через интернет программа использует публичные STUN-серверы Google (`stun.l.google.com`), это нужно только для установления соединения. Сервера-ретранслятора (TURN) в программе по умолчанию нет, поэтому за строгим NAT соединение может не установиться.
